# Spatial Insight · Orange Industrial V3

## 方向

基于 V2 橙黑方案进一步靠近 Figma `3D and immersive elements` 参考案例，同时适配数据密集型竞品洞察工作台。

## V3 设计约束

- 黑、白、灰承担主要信息秩序，橙色仅作为工业标记色。
- 不使用 CSS 渐变。
- 不使用常规投影。
- 通过黑白反差、1–2px 边界、轴线、错位线框、尺度和字体建立层级。
- 所有功能性容器均采用 `0px` 圆角。
- 中文显示标题使用超粗、紧字距排版；技术标签使用 IBM Plex Mono。
- 主按钮为黑底白字，橙色只保留为 5px 信号点或焦点轮廓。
- 核心按钮统一采用 1.7px、方端、miter join 的线性 SVG 图标。
- Tab 固定 200px，严格单行省略。
- 支持 `prefers-reduced-motion`。

## 橙色使用位置

- 品牌坐标点
- Pilot 标记
- 工作区系统编号
- 当前 Tab 的 3px 底线
- Hero 系统短线和几何板
- 区块序号
- 卡片状态及定位点
- 键盘焦点轮廓

橙色不用于大面积背景、正文、卡片底色或矩阵数据区。

## 与正式产品的关系

这是独立的视觉 Pilot，不读取或写入业务数据，也未修改正式 `index.html`。
