# Spatial Insight · Orange Industrial V3

## 方向

基于 V2 橙黑方案进一步靠近 Figma `3D and immersive elements` 参考案例，同时适配数据密集型竞品洞察工作台。

## V3 设计约束

- 黑、白、灰承担主要信息秩序，橙色遵循 10%–15% 的视觉预算。
- 不使用 CSS 渐变。
- 不使用常规投影。
- 通过黑白反差、1–2px 边界、轴线、错位线框、尺度和字体建立层级。
- 所有功能性容器均采用 `0px` 圆角。
- 分割线采用三级 Token：一级黑色、二级深灰、三级浅灰。
- 中文显示标题使用超粗、紧字距排版；技术标签使用 IBM Plex Mono。
- 最高优先级按钮为橙底黑字，并斜切左上、右下角；次级按钮仍为标准矩形、白底黑框。
- 核心按钮统一采用 1.7px、方端、miter join 的线性 SVG 图标。
- Tab 固定 200px，严格单行省略。
- 支持 `prefers-reduced-motion`。

## 橙色使用位置

- 品牌坐标点
- Pilot 标记
- 工作区系统编号
- 添加 Tab、添加竞品等最高优先级按钮
- 当前 Tab 的 3px 底线
- Hero 系统短线和几何板
- 区块序号
- 卡片状态及定位点
- 键盘焦点轮廓

橙色不用于正文、普通卡片底色、矩阵数据区或次级按钮。

## 分割线层级

- `line-strong / #111111`：页面主结构、Hero 外框、区块标题线、矩阵外框。
- `line-medium / #595959`：Tab 分隔、卡片组边界、次级区域边界。
- `line-subtle / #C9C8C3`：矩阵单元格、空间轴线和内容内部辅助线。

## 与正式产品的关系

这是独立的视觉 Pilot，不读取或写入业务数据，也未修改正式 `index.html`。


## Cross Grid preview

- 页面底色使用 44px 重复间距的小十字。
- 单个十字横纵各 6px、线宽 0.6px、颜色 #C9C8C3。
- 不使用大锚点、圆环或橙色中心点。
- 使用内联 SVG background-image，不使用渐变。
- 白色内容面板保持实底，不让网格穿透数据内容。
- 橙色 Primary Button 使用透明边框，不显示黑边。
